# 洋食まつもと 探し物ゲーム

## 遊び方

このフォルダでローカルWebサーバーを起動し、表示された `http://localhost:4173` をブラウザで開きます。

```sh
python3 -m http.server 4173
```

お題に表示された品を画面内でクリックしてください。正解は緑、不正解は赤で反応します。60秒以内に8つ全て見つければクリアです。

## 内容

- Phaser 3 を使った1画面のゲーム
- 8つのクリック判定
- 60秒のカウントダウン
- 正解・不正解・時間切れ・クリアの表示
- 正解・不正解・クリア・時間切れの効果音
- 「もう一度あそぶ」で最初から再開

Phaser 本体とフォントはCDNから読み込みます。初回起動時はインターネット接続が必要です。

## GitHub Pagesで公開するには

このフォルダを含むプロジェクトをGitHubリポジトリの `main` ブランチへプッシュしてください。含まれているGitHub Actionsの設定により、`outputs/hidden-object-game` がGitHub Pagesとして自動公開されます。リポジトリの **Settings → Pages → Build and deployment** では、ソースに **GitHub Actions** を選択します。
